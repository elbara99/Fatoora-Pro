# Roadmap

## v1.0 (Current)

- [x] Product management (CRUD with auto-generated codes)
- [x] CSV product import
- [x] Invoice creation with line items
- [x] Invoice editing
- [x] Invoice history browsing and search
- [x] Professional A4 invoice printing
- [x] Bilingual interface (English / Arabic)
- [x] SQLite local storage
- [x] Dashboard with daily/monthly sales overview
- [x] Application settings (company info, logo, language)

## v1.1 (Planned)

- [ ] Database backup and restore
- [ ] Invoice search by date range, amount, and product
- [ ] PDF export in addition to print
- [ ] Settings improvements (paper size presets, default values)

## v1.2 (Planned)

- [ ] Sales reports and analytics
- [ ] Expense tracking
- [ ] Payment recording per invoice
- [ ] Keyboard shortcut cheat sheet

## v2.0 (Future)

- [ ] Multi-user support with permissions
- [ ] Cloud backup and sync
- [ ] REST API for integration
- [ ] Mobile companion app
